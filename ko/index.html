누구나 간편하고 안심할 수 있는
AI 노트

데이터는 완전 로컬 저장. 자신의 API 키로 작동하여 안심. 과거 노트를 맥락으로 활용해 AI와 함께 문서를 작성하는 macOS 앱.


주요 기능

AI와 공동 편집

AI 요청과 직접 편집을 자유롭게 조합. 인간과 AI가 하나의 문서를 함께 완성하는 새로운 경험.

사용할수록 똑똑해지는

AI가 과거 노트와 프로젝트를 이해합니다. 지식을 축적하여 맥락에 맞는 지원을 제공합니다.

다양한 AI 스킬

웹 검색, 문서 작성, 파일 첨부, 음성 입력, 노트 검색, 이미지 인식.

멀티 모델 지원

Gemini / Claude에서 최적의 모델을 선택. BYOK 방식으로 자신의 API 키로 사용.

완전 로컬 저장

모든 데이터는 Mac에만 저장됩니다. 외부 서버 업로드 없음. 기밀 정보도 안심하고 취급 가능.

이런 장면에서 활약합니다

📝

회의록 작성

회의 메모에서 AI가 회의록을 정리. 이전 회의 내용을 바탕으로 요점을 정리합니다.

📋

기획서 & 제안서

AI가 프로젝트 경과를 파악. 배경과 목적에 기반한 설득력 있는 문서를 작성합니다.

📚

조사 & 학습 노트

웹 검색으로 최신 정보를 수집하며 노트에 축적. 과거 조사 결과를 활용한 심층 분석이 가능.

💡

아이디어 브레인스토밍

떠오르는 것을 메모하세요. AI가 과거 아이디어와 연결하여 새로운 영감을 이끌어냅니다.

⚙️

기술 문서

설계 메모와 사양을 AI가 정리. 이미지와 PDF를 첨부하여 기술적 맥락을 유지한 문서화.

✏️

일보 & 회고

AI가 일일 기록을 분석. 진행 상황과 인사이트를 축적하여 주보/월보 작성을 지원합니다.
