共同編集

ひとつのドキュメントを、AI と一緒に仕上げる。

AI に書いてもらう箇所と、自分で直す箇所を混ぜ合わせながら、同じドキュメントを協働で仕上げていく。チャット越しの提案でもコメント返しでもない、新しいドキュメント作成のかたちです。

文脈

過去のノートが、そのまま文脈になる。

同じプロジェクトのノートやファイルを、AI が自動で読み込みます。「これも先に読んで」と一つひとつ貼り付ける手間は、もう必要ありません。前提から説明し直さなくても、話が通じます。

  • 関連するノートを自動で参照
  • ノート横断のベクトル検索
  • 使うほどに、あなた専用に
徹底リサーチ

頼むだけで、引用付きレポートが手元に。

「〜について調べて」と一言頼めば、AI が自分で計画を立て、Web を巡り、引用付きの調査レポートをノートにまとめます。実行前に予想コストと所要時間を確認できるので、ふだんのチャットと同じ感覚で頼めます。

いつも隣に

本文の隣で、その場で AI に相談。

ドキュメントの横にあるチャットから、ドラフトの作成も、文章の調整も、その場で依頼。あなたの考えを、AI が次々とドキュメントに落とし込みます。視線を移すだけで、共同作業がはじまります。

プライバシー

ノートは、あなたの端末のなかだけに。

AI を使うために、すべてをクラウドに預ける必要はありません。Teeby は「あなたの端末」と「あなたの API キー」のふたつだけで動くように設計されています。

ノート本文は完全にローカル保存

Teeby のサーバーにノートが送られることはありません。バックアップも同期も、ご自身の環境で完結します。

BYOK — ご自身の API キーで動作

AI へのリクエストは Gemini / Claude に直接。料金も利用規約も、各プロバイダーとの関係で完結します。

中継サーバーを置かない

Teeby が通信を中継することはありません。内容のログも残らないので、機密性の高い情報でも安心です。

よくあるご質問

Teeby とは何ですか？
Teeby は、書きためたメモを文脈に AI と一緒に文章を仕上げる Mac / iPad 向けノートアプリです。Deep Research、計画立案、タスク管理、セカンドオピニオン、Web 検索、音声入力、画像の読み取り、ノート横断検索を備え、データは完全ローカル保存、BYOK（Bring Your Own Key）方式で Gemini または Claude を直接利用します。
料金はかかりますか？
App Store からのダウンロードは無料で、ノート 10 件までは無料のままご利用いただけます。10 件を超えて作成・管理したい場合は、App Store のアプリ内課金（買い切り型のプレミアム版アップグレード）で制限を解除できます。月額のサブスクリプションはありません。AI 機能は BYOK（Bring Your Own Key）方式で、お持ちの Gemini または Claude API キーをそのまま使うため、AI 利用料金は各プロバイダの料金体系に従って、ご自身で従量課金されます。
ノートはどこに保存されますか？
ノート本文はあなたの端末（Mac または iPad）のアプリサンドボックス内にのみ保存されます。Teeby のサーバーに送信されることは一度もありません。バックアップや同期もご自身の環境で完結します。
Deep Research（徹底リサーチ）とは何ですか？
「〜について調べて」と頼むだけで、AI が自分で計画を立て、Web を巡って引用付きの調査レポートをノートにまとめる機能です。実行前に予想コストと所要時間を確認できます。Gemini API の有料ティアが必要です。
対応する AI モデルは？
Gemini 3.6 Flash / 3.5 Flash Lite と、Claude Opus 5 / Sonnet 5 に対応しています。自動切り替えモード（プロンプトに応じて最適なモデルを毎回判定）と手動選択の両方が利用できます。
動作環境は？
macOS 14 以降、または iPadOS 17 以降が必要です。Mac は Apple Silicon と Intel の両方で動作します。
