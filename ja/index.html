よくあるご質問

Teeby について、よく寄せられる質問と回答です。

Teeby とは何ですか？
Teeby は、書きためたメモを文脈に AI と一緒に文章を仕上げる Mac / iPad 向けノートアプリです。Deep Research、計画立案、タスク管理、セカンドオピニオン、Web 検索、音声入力、画像の読み取り、ノート横断検索を備え、データは完全ローカル保存、BYOK（Bring Your Own Key）方式で Gemini または Claude を直接利用します。
料金はかかりますか？
App Store からのダウンロードは無料で、ノート 10 件までは無料のままご利用いただけます。10 件を超えて作成・管理したい場合は、App Store のアプリ内課金（買い切り型のプレミアム版アップグレード）で制限を解除できます。月額のサブスクリプションはありません。AI 機能は BYOK（Bring Your Own Key）方式で、お持ちの Gemini または Claude API キーをそのまま使うため、AI 利用料金は各プロバイダの料金体系に従って、ご自身で従量課金されます。
ノートはどこに保存されますか？
ノート本文はあなたの端末（Mac または iPad）のアプリサンドボックス内にのみ保存されます。Teeby のサーバーに送信されることは一度もありません。バックアップや同期もご自身の環境で完結します。
Deep Research（徹底リサーチ）とは何ですか？
「〜について調べて」と頼むだけで、AI が自分で計画を立て、Web を巡って引用付きの調査レポートをノートにまとめる機能です。実行前に予想コストと所要時間を確認できます。Gemini API の有料ティアが必要です。
対応する AI モデルは？
Gemini 3.1 Pro / 3 Flash / 3.1 Flash Lite と、Claude Opus 4.7 / Sonnet 4.6 に対応しています。自動切り替えモード（プロンプトに応じて最適なモデルを毎回判定）と手動選択の両方が利用できます。
動作環境は？
macOS 14 以降、または iPadOS 17 以降が必要です。Mac は Apple Silicon と Intel の両方で動作します。
