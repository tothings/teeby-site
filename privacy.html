プライバシーポリシー

Teeby — 最終更新日: 2026年3月7日

はじめに

Teeby（以下「本アプリ」）は、Akinori Tokita（以下「開発者」）が開発・提供するmacOS向けAI搭載ノートアプリケーションです。本プライバシーポリシーは、本アプリにおけるユーザーの個人情報の取り扱いについて説明します。

データの収集について

本アプリは、ユーザーの個人情報を一切収集しません。

  • ノート、プロジェクト、設定情報を含むすべてのデータは、ユーザーのMac上にのみ保存されます。
  • 開発者のサーバーへのデータ送信は一切行いません。
  • ユーザー分析やトラッキングツールは使用していません。

サードパーティサービスへのデータ送信

本アプリのAI機能は、ユーザーが自ら設定したAPIキー（BYOK: Bring Your Own Key）を使用して、以下のサードパーティサービスにデータを送信します。APIキーを設定しない場合、外部サービスへのデータ送信は一切行われません。

送信されるデータの種類

  • ノートのテキスト内容（セマンティック検索用エンベディング処理）
  • AIチャットへの入力テキストおよび添付ファイル
  • AIが参照する関連ノートの内容（コンテキスト情報）
  • チャットの会話履歴（セッション内のみ）
  • 音声データ（音声入力使用時、テキスト変換後に即時破棄。保存されることはありません）
  • システム情報（現在日時・タイムゾーンのみ）

送信先サービス

  • Google LLC（Google AI Studio / Gemini API）
    用途: AIチャット、ノート検索用エンベディング、Web検索、音声入力
    エンドポイント: generativelanguage.googleapis.com
  • Anthropic PBC（Claude API）
    用途: AIチャット（ユーザーがClaudeモデルを選択した場合のみ）
    エンドポイント: api.anthropic.com

ユーザーの同意

本アプリでは、データ送信に関して以下の2段階で明示的な同意を取得します：

  • 初回起動時の利用規約・プライバシーポリシー同意画面
  • APIキー設定時のデータ共有同意画面（送信データと送信先を具体的に明示）

データの保持について

本アプリはデータを中継・保持しません。ユーザーのデバイスからAPIプロバイダへ直接送信されます。送信されたデータの保持・取り扱いは、各サービスのプライバシーポリシーに準じます：

  • Google プライバシーポリシー
  • Anthropic プライバシーポリシー

マイクの使用

本アプリは、音声入力機能のためにマイクへのアクセスを要求することがあります。マイクから取得した音声データは、一時的にAI APIへ送信されテキストに変換された後、ローカルに破棄されます。音声データが保存されることはありません。

APIキーの管理

ユーザーが設定したAPIキーは、お使いのMac上のアプリケーション設定ファイルにローカル保存されます。APIキーが開発者のサーバーに送信されることはありません。

お子様のプライバシー

本アプリは特定の年齢層を対象としていません。個人情報の収集を行わないため、お子様のプライバシーに関する特別なリスクはありません。

プライバシーポリシーの変更

本プライバシーポリシーは、必要に応じて更新されることがあります。重要な変更がある場合は、アプリのアップデートを通じてお知らせします。

Privacy Policy

Teeby — Last Updated: March 7, 2026

Introduction

Teeby ("the App") is an AI-powered note-taking application for macOS, developed by Akinori Tokita ("the Developer"). This Privacy Policy explains how user information is handled within the App.

Data Collection

The App does not collect any personal information from users.

  • All data, including notes, projects, and settings, is stored exclusively on the user's Mac.
  • No data is transmitted to the Developer's servers.
  • No analytics or tracking tools are used.

Data Transmission to Third-Party Services

The App's AI features transmit data to the following third-party services using API keys provided by the user (BYOK: Bring Your Own Key). If you do not set up API keys, no data is transmitted to any external service.

Types of Data Transmitted

  • Note text content (for semantic search embedding processing)
  • AI chat input text and attached files
  • Related note content referenced by AI (context information)
  • Chat conversation history (within the session only)
  • Audio data (when using voice input; immediately discarded after text conversion and never stored)
  • System information (current date/time and timezone only)

Recipient Services

  • Google LLC (Google AI Studio / Gemini API)
    Purpose: AI chat, note search embeddings, web search, voice input
    Endpoint: generativelanguage.googleapis.com
  • Anthropic PBC (Claude API)
    Purpose: AI chat (only when user selects a Claude model)
    Endpoint: api.anthropic.com

User Consent

The App obtains explicit user consent for data sharing through a two-step process:

  • Terms of Service and Privacy Policy consent screen on first launch
  • Data sharing consent screen when setting up API keys (explicitly listing data types and recipients)

Data Retention

The App does not relay or retain any data. Data is transmitted directly from the user's device to the API provider. Retention and handling of transmitted data is governed by each service's privacy policy:

  • Google Privacy Policy
  • Anthropic Privacy Policy

Microphone Usage

The App may request access to the microphone for voice input functionality. Audio data from the microphone is temporarily sent to the AI API for text transcription and then discarded locally. No audio data is stored.

API Key Management

API keys configured by the user are stored locally in the application's settings file on your Mac. API keys are never transmitted to the Developer's servers.

Children's Privacy

The App is not directed at any specific age group. Since no personal information is collected, there are no special privacy risks for children.

Changes to This Policy

This Privacy Policy may be updated as needed. Significant changes will be communicated through app updates.
