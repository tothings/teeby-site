プライバシーポリシー

Teeby — 最終更新日: 2026年3月1日

はじめに

Teeby（以下「本アプリ」）は、Akinori Tokita（以下「開発者」）が開発・提供するmacOS向けAI搭載ノートアプリケーションです。本プライバシーポリシーは、本アプリにおけるユーザーの個人情報の取り扱いについて説明します。

データの収集について

本アプリは、ユーザーの個人情報を一切収集しません。

  • ノート、プロジェクト、設定情報を含むすべてのデータは、ユーザーのMac上にのみ保存されます。
  • 開発者のサーバーへのデータ送信は一切行いません。
  • ユーザー分析やトラッキングツールは使用していません。

外部サービスとの通信

本アプリのAI機能は、ユーザーが自ら設定したAPIキー（BYOK: Bring Your Own Key）を使用して、以下の外部サービスと通信します：

  • Google AI Studio (Gemini API) — AIチャット、ノート検索、Web検索、音声入力に使用
  • Anthropic (Claude API) — AIチャットに使用（オプション）

これらのサービスへ送信されるデータ（チャットメッセージ、ノート内容等）の取り扱いは、各サービスのプライバシーポリシーに準じます：

  • Google プライバシーポリシー
  • Anthropic プライバシーポリシー

マイクの使用

本アプリは、音声入力機能のためにマイクへのアクセスを要求することがあります。マイクから取得した音声データは、一時的にAI APIへ送信されテキストに変換された後、ローカルに破棄されます。音声データが保存されることはありません。

APIキーの管理

ユーザーが設定したAPIキーは、お使いのMac上のアプリケーション設定ファイルにローカル保存されます。APIキーが開発者のサーバーに送信されることはありません。

お子様のプライバシー

本アプリは特定の年齢層を対象としていません。個人情報の収集を行わないため、お子様のプライバシーに関する特別なリスクはありません。

プライバシーポリシーの変更

本プライバシーポリシーは、必要に応じて更新されることがあります。重要な変更がある場合は、アプリのアップデートを通じてお知らせします。

Privacy Policy

Teeby — Last Updated: March 1, 2026

Introduction

Teeby ("the App") is an AI-powered note-taking application for macOS, developed by Akinori Tokita ("the Developer"). This Privacy Policy explains how user information is handled within the App.

Data Collection

The App does not collect any personal information from users.

  • All data, including notes, projects, and settings, is stored exclusively on the user's Mac.
  • No data is transmitted to the Developer's servers.
  • No analytics or tracking tools are used.

Communication with External Services

The App's AI features communicate with the following external services using API keys provided by the user (BYOK: Bring Your Own Key):

  • Google AI Studio (Gemini API) — Used for AI chat, note search, web search, and voice input
  • Anthropic (Claude API) — Used for AI chat (optional)

Data sent to these services (chat messages, note content, etc.) is handled according to each service's privacy policy:

  • Google Privacy Policy
  • Anthropic Privacy Policy

Microphone Usage

The App may request access to the microphone for voice input functionality. Audio data from the microphone is temporarily sent to the AI API for text transcription and then discarded locally. No audio data is stored.

API Key Management

API keys configured by the user are stored locally in the application's settings file on your Mac. API keys are never transmitted to the Developer's servers.

Children's Privacy

The App is not directed at any specific age group. Since no personal information is collected, there are no special privacy risks for children.

Changes to This Policy

This Privacy Policy may be updated as needed. Significant changes will be communicated through app updates.
