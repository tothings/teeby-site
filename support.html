よくある質問

Q: APIキーはどこで取得できますか？

Google AI StudioのAPIキーは Google AI Studio から取得できます。Claude APIキーは Anthropic Console から取得できます。

Q: データはどこに保存されますか？

すべてのノート、プロジェクト、設定データはお使いのMacのローカルストレージにのみ保存されます。外部サーバーへのアップロードは一切行いません。

Q: APIキーなしでも使えますか？

はい。ノートの作成・編集機能はAPIキーなしでご利用いただけます。AI機能（チャット、検索、音声入力）のみAPIキーが必要です。

Q: どのAIモデルに対応していますか？

Google Gemini（Gemini 2.5 Pro, Flash等）およびAnthropic Claude（Sonnet, Opus等）に対応しています。

FAQ

Q: Where can I get an API key?

You can get a Google AI Studio API key from Google AI Studio. Claude API keys are available from Anthropic Console.

Q: Where is my data stored?

All notes, projects, and settings are stored exclusively on your Mac's local storage. No data is uploaded to external servers.

Q: Can I use the app without an API key?

Yes. Note creation and editing features work without an API key. Only AI features (chat, search, voice input) require an API key.

Q: Which AI models are supported?

The app supports Google Gemini (Gemini 2.5 Pro, Flash, etc.) and Anthropic Claude (Sonnet, Opus, etc.).
